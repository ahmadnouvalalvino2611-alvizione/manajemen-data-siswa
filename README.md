# Sistem Manajemen Data Siswa

Aplikasi berbasis web untuk mengelola data siswa 

## 1. Fitur Aplikasi

- Login, registrasi, dan logout pengguna.
- Dashboard untuk menampilkan ringkasan jumlah siswa.
- Menampilkan daftar data siswa.
- Menambahkan data siswa.
- Melihat detail data siswa.
- Mengedit data siswa.
- Menghapus data siswa.
- Mencari data siswa.
- Validasi input untuk menjaga kelengkapan data.

## 2. Teknologi yang Digunakan

- Laravel 12
- PHP
- MySQL
- Bootstrap 5
- HTML, CSS, dan JavaScript
- Composer dan Node.js

## 3. Panduan Penggunaan Aplikasi

### a. Registrasi dan Login

1. Buka halaman aplikasi.
2. Pilih menu Register untuk membuat akun.
3. Isi nama, email, dan password.
4. Setelah registrasi, masuk menggunakan akun tersebut melalui halaman Login.
5. Klik Logout jika ingin keluar dari aplikasi.

### b. Dashboard

Setelah berhasil login, pengguna akan diarahkan ke Dashboard. Halaman ini menampilkan ringkasan:
- Total siswa.
- Jumlah siswa laki-laki.
- Jumlah siswa perempuan.
- Jumlah kelas.

### c. Mengelola Data Siswa

Pilih menu **Data Siswa** untuk membuka daftar siswa.

- **Tambah:** Klik tombol Tambah Siswa, isi formulir, kemudian simpan.
- **Detail:** Klik tombol Detail untuk melihat informasi lengkap siswa.
- **Edit:** Klik tombol Edit untuk mengubah informasi siswa, kemudian simpan perubahan.
- **Hapus:** Klik tombol Hapus untuk menghapus data siswa setelah melakukan konfirmasi.
- **Cari:** Gunakan kolom pencarian untuk menemukan data siswa.

## 4. Data yang Dikelola

Informasi siswa meliputi:
- NIS
- Nama siswa
- Jenis kelamin
- Tempat lahir
- Tanggal lahir
- Alamat
- Kelas
- Jurusan
- Nomor HP
